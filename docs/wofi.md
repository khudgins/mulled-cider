# Mulled Cider for wofi

Launcher styling for wofi.

## Installation

Copy or symlink to wofi's stylesheet:

```sh
mkdir -p ~/.config/wofi
ln -s /path/to/wofi-mulled-cider.css ~/.config/wofi/style.css
```

Or pass it on the command line:

```sh
wofi --show drun --style /path/to/wofi-mulled-cider.css
```

## What's Themed

- **Window**: dark background with a golden border and rounded corners
- **Search input**: darkest background, golden border when focused
- **Entries**: selection brown highlight on the selected entry, with brighter text
